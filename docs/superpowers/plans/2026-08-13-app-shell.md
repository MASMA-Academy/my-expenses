# MyXpenses App Shell Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the default Flutter counter-app scaffold with MyXpenses' real entry point: a themed `MaterialApp` with a 4-tab bottom-navigation shell (Home/Reports/History/Budget) and a center FAB that pushes the Add Transaction screen.

**Architecture:** `main.dart` calls `runApp`, wrapping the app in a `ChangeNotifierProvider<AppState>` (currently empty, for future state). `app.dart` builds the `MaterialApp` using a theme defined in `theme/app_theme.dart` and sets `home` to `MainNavigation` (`navigation/main_navigation.dart`), which holds an `IndexedStack` of the 4 tab screens plus a `BottomAppBar`/`FloatingActionButton` combo. All 5 screens in `lib/screens/` get minimal placeholder bodies — no real data or logic in this plan.

**Tech Stack:** Flutter (Material 3), `provider` package for state, `google_fonts` package for the Quicksand typeface.

## Global Constraints

- Color palette: primary green `#7FC8A9`, secondary pink `#F2A6B3`, background cream `#FDF3EC`, surface white `#FFFFFF`.
- Font: Quicksand via `google_fonts`.
- Bottom nav has exactly 4 tabs (Home, Reports, History, Budget); Add Transaction is pushed via the FAB, not a 5th tab.
- No real transaction/budget/category data or persistence in this plan — screens are static placeholders.
- `flutter analyze` must report no issues after every task.

### Task 2: App theme

**Files:**
- Create: `lib/theme/app_theme.dart`

**Interfaces:**
- Consumes: `google_fonts` package (Task 1).
- Produces: `AppColors` class with static `Color` constants `primary`, `secondary`, `background`, `surface`. `AppTheme` class with static `ThemeData get theme`.

- [ ] **Step 1: Write the theme file**

```dart
import 'package:flutter/material.dart';
import 'package:google_fonts/google_fonts.dart';

class AppColors {
  AppColors._();

  static const Color primary = Color(0xFF7FC8A9);
  static const Color secondary = Color(0xFFF2A6B3);
  static const Color background = Color(0xFFFDF3EC);
  static const Color surface = Color(0xFFFFFFFF);
}

class AppTheme {
  AppTheme._();

  static ThemeData get theme {
    final base = ThemeData(
      useMaterial3: true,
      colorScheme: ColorScheme.fromSeed(
        seedColor: AppColors.primary,
        primary: AppColors.primary,
        secondary: AppColors.secondary,
        surface: AppColors.surface,
      ),
      scaffoldBackgroundColor: AppColors.background,
      textTheme: GoogleFonts.quicksandTextTheme(),
    );

    return base.copyWith(
      appBarTheme: AppBarTheme(
        backgroundColor: AppColors.background,
        foregroundColor: Colors.black87,
        elevation: 0,
        titleTextStyle: GoogleFonts.quicksand(
          fontSize: 20,
          fontWeight: FontWeight.w600,
          color: Colors.black87,
        ),
      ),
      bottomNavigationBarTheme: const BottomNavigationBarThemeData(
        backgroundColor: AppColors.surface,
        selectedItemColor: AppColors.primary,
        unselectedItemColor: Colors.grey,
      ),
      floatingActionButtonTheme: const FloatingActionButtonThemeData(
        backgroundColor: AppColors.primary,
        foregroundColor: Colors.white,
      ),
    );
  }
}
```

### Task 5: Main navigation shell

**Files:**
- Create: `lib/navigation/main_navigation.dart`

**Interfaces:**
- Consumes: `DashboardScreen`, `ReportScreen`, `HistoryScreen`, `BudgetScreen`, `TransactionScreen` (Task 4).
- Produces: `class MainNavigation extends StatefulWidget` — a `Scaffold` with 4-tab `IndexedStack` body, centered-docked FAB, and a notched bottom bar.

- [ ] **Step 1: Write the navigation shell**

```dart
import 'package:flutter/material.dart';

import '../screens/budget_screen.dart';
import '../screens/dashboard_screen.dart';
import '../screens/history_screen.dart';
import '../screens/report_screen.dart';
import '../screens/transaction_screen.dart';

class MainNavigation extends StatefulWidget {
  const MainNavigation({super.key});

  @override
  State<MainNavigation> createState() => _MainNavigationState();
}

class _MainNavigationState extends State<MainNavigation> {
  int _selectedIndex = 0;

  static const List<Widget> _tabs = [
    DashboardScreen(),
    ReportScreen(),
    HistoryScreen(),
    BudgetScreen(),
  ];

  void _onTabTapped(int index) {
    setState(() {
      _selectedIndex = index;
    });
  }

  void _openAddTransaction() {
    Navigator.push(
      context,
      MaterialPageRoute(builder: (_) => const TransactionScreen()),
    );
  }

  @override
  Widget build(BuildContext context) {
    return Scaffold(
      body: IndexedStack(
        index: _selectedIndex,
        children: _tabs,
      ),
      floatingActionButton: FloatingActionButton(
        onPressed: _openAddTransaction,
        child: const Icon(Icons.add),
      ),
      floatingActionButtonLocation: FloatingActionButtonLocation.centerDocked,
      bottomNavigationBar: BottomAppBar(
        shape: const CircularNotchedRectangle(),
        notchMargin: 8,
        child: Row(
          mainAxisAlignment: MainAxisAlignment.spaceAround,
          children: [
            _NavBarItem(
              icon: Icons.home_rounded,
              label: 'Home',
              isSelected: _selectedIndex == 0,
              onTap: () => _onTabTapped(0),
            ),
            _NavBarItem(
              icon: Icons.pie_chart_rounded,
              label: 'Reports',
              isSelected: _selectedIndex == 1,
              onTap: () => _onTabTapped(1),
            ),
            const SizedBox(width: 40),
            _NavBarItem(
              icon: Icons.receipt_long_rounded,
              label: 'History',
              isSelected: _selectedIndex == 2,
              onTap: () => _onTabTapped(2),
            ),
            _NavBarItem(
              icon: Icons.savings_rounded,
              label: 'Budget',
              isSelected: _selectedIndex == 3,
              onTap: () => _onTabTapped(3),
            ),
          ],
        ),
      ),
    );
  }
}

class _NavBarItem extends StatelessWidget {
  const _NavBarItem({
    required this.icon,
    required this.label,
    required this.isSelected,
    required this.onTap,
  });

  final IconData icon;
  final String label;
  final bool isSelected;
  final VoidCallback onTap;

  @override
  Widget build(BuildContext context) {
    final color =
        isSelected ? Theme.of(context).colorScheme.primary : Colors.grey;

    return InkWell(
      onTap: onTap,
      child: Padding(
        padding: const EdgeInsets.symmetric(horizontal: 8, vertical: 4),
        child: Column(
          mainAxisSize: MainAxisSize.min,
          children: [
            Icon(icon, color: color),
            Text(label, style: TextStyle(color: color, fontSize: 12)),
          ],
        ),
      ),
    );
  }
}
```
